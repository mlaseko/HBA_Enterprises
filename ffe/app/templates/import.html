Upload the Excel

Adding: start from Download the template. Its Rooms sheet lists this project's rooms and areas (add a floor, a room or an area as a new row) and its Shopping List has dropdowns for the room, category, unit and status. The Room dropdown also offers All bedrooms, All bathrooms, All rooms, All areas and All on Ground floor; several rooms can be typed with ; between them. One row then becomes one item per room, each with its own code.

Updating: press Export all items, change what you need in Excel and import the file. A row whose Code is an existing item's code updates that item: only the cells you fill in change, a - clears a cell, and the code never changes. Rows without a code are added as new items.

Nothing is saved until you confirm: the next screen lists every item the file would add or change. Rooms are created or updated first (matched by their code, never duplicated). Then each item row: a code that matches an existing item updates it, anything else is added as a new item. The Kinondoni list format imports too; columns are matched by their headers and extra columns are ignored.
